# wikichatbot
A small chatbot web application built with **Python** and **Flask**. It uses an **NLTK + Keras** deep learning model to understand user questions and respond naturally through a clean chat interface. For knowledge-based queries, it automatically fetches concise summaries from **Wikipedia**.
